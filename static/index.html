Saved API keys

Keys are stored on the server and shown masked. Click the 🗑 icon to delete a key: its row is removed completely, and if it was the active model, questions answer “The model is not configured” until you add a key.

A key is also provided through the LLM_API_KEY environment variable. Deleting it here lasts until the app restarts; remove the variable to delete it for good.

Add or update a key

Choose a provider, paste its API key and press Submit. The key is saved to data/settings.json on the server and that provider becomes the active model. Keys are never sent back to the browser in full.
